# tokyo-highschool-simulator

東京都立高校入試(一般入試)向けの、得点シミュレーターです。
内申点(通知表の評定)と目標の総合得点を入力すると、入試当日の学力検査で何点必要かを計算します。

## 使い方(プログラミング不要です)

このアプリは `index.html` という1つのファイルだけで動く、シンプルなWebアプリです。
特別な準備(インストールなど)は一切不要です。

1. このリポジトリの `index.html` をダウンロード(またはこのリポジトリごとダウンロード)します。
2. `index.html` を **ダブルクリック** してください。お使いのブラウザ(Google Chrome、Safari、Edgeなど)が自動的に開き、そのまま使えます。

インターネットに繋がっていなくても動作します(通信は一切行いません)。入力した内容もお使いの端末の外へは送信されません。

## できること

1. 9教科(国語・社会・数学・理科・英語・音楽・美術・保健体育・技術家庭)の内申点(5段階)を入力
2. 一般入試のルールに沿って「換算内申(65点満点)」を自動計算
3. 換算内申を「調査書点(300点満点)」に自動換算
4. 志望校の「学力検査:調査書」の比率(標準は7:3)を選択
5. 目標にしたい総合得点(1000点満点)を入力すると、当日の学力検査(500点満点)で何点取ればよいかを自動計算
6. 国語・数学・英語・社会・理科、それぞれの目標点を入力して、必要点数に届くかを確認

## 注意

このツールはあくまで学習の目安を計算する簡易シミュレーターです。実際の選抜方法・比率・配点は必ず志望校の募集要項や学校説明会の情報でご確認ください。
